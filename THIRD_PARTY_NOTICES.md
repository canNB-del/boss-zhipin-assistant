# Third-party components

This extension bundles Mozilla PDF.js (`pdfjs-dist` version 5.4.149) for local PDF text extraction, including character maps for CJK PDFs.

- Project: https://github.com/mozilla/pdf.js
- Distribution: https://www.npmjs.com/package/pdfjs-dist/v/5.4.149
- License: Apache License 2.0. See `LICENSE.pdfjs.txt` and the copyright notices in the bundled files.
- Files: `pdf.min.mjs`, `pdf.worker.min.mjs`, `pdf-cmaps.mjs` (the distribution's `.bcmap` files repackaged as base64 data).

The license above applies to these third-party components, not automatically to the rest of the extension.
